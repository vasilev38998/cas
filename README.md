# Сладкий Каскад — статическая демо-игра

Полностью клиентская демо-версия слота без регистрации, базы данных и серверной части.

## Запуск

Загрузите все файлы репозитория в корень обычного статического хостинга. Сборка, Node.js и база данных не нужны — точка входа `index.html`.

## Реализовано

- адаптивное поле 7×7 для компьютера и телефона;
- медленная поэтапная «прокрутка» символов с поколоночной остановкой;
- отдельная анимация ожидания третьего бонусного символа;
- кластерные выигрыши из 5+ соседних символов и каскадные падения;
- растущее комбо каскадов: ×1 → ×1.20 → ×1.45 → ×1.75 → далее до ×3;
- «Сладкий взрыв» на длинных сериях каскадов с добавлением новых множителей;
- шкала «Сладкий шторм»: после зарядки следующее обычное вращение получает 6 усиленных клеток;
- фиксированные множители клеток до ×100;
- во фриспинах множители сохраняются между вращениями;
- 3/4/5+ бонусных символов дают 8/10/12 фриспинов;
- демо-активация обычного и супер-бонуса за виртуальные кредиты;
- частицы, вспышки, подсветка поля, конфетти и экранные уведомления;
- автоигра ×20, турбо-режим и управление пробелом;
- звуки без внешних аудиофайлов через Web Audio API;
- оригинальные SVG-символы прямо в коде, без внешних ассетов;
- интерфейс полностью на русском языке, отображение суммы в RUB;
- баланс, фриспины, множители и заряд шторма сохраняются в `localStorage` браузера;
- отдельная компоновка для узких экранов и мобильного landscape, поддержка safe-area.

## Важно

Это демонстрационная клиентская игра. Все кредиты виртуальные и не имеют денежной ценности. RNG, баланс и игровая логика выполняются в браузере и могут быть изменены пользователем, поэтому эта версия не подходит для реальных денежных ставок. Для real-money проекта потребуются серверный кошелёк/ledger, защищённый RNG, аудит, журнал транзакций и соблюдение требований применимой юрисдикции.
