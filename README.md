# CandyClub — аккаунтная игровая платформа

PHP/MySQL-сайт с регистрацией, авторизацией, серверным виртуальным балансом, журналом операций и серверным расчётом игровых раундов.

## Стек

- PHP 8.2+
- MySQL / MariaDB
- PDO
- HTML/CSS/JavaScript без Node.js и без сборки на хостинге
- PHP sessions + HttpOnly/SameSite cookies
- `password_hash()` / `password_verify()`
- CSRF-защита форм и игрового API
- GitHub Actions: PHP lint, JavaScript syntax check и smoke-тест игровых движков

Проект рассчитан на обычный shared-хостинг вроде Beget.

## Установка

1. Создайте MySQL-базу и пользователя базы в панели хостинга.
2. Импортируйте `schema.sql`.
3. Скопируйте `app/config.example.php` в `app/config.php`.
4. Заполните `host`, `name`, `user`, `pass`.
5. Загрузите проект в корень домена.
6. Для диагностики окружения доступен `health.php`.

`app/config.php` находится в `.gitignore`, поэтому пароль базы не попадает в GitHub.

## Библиотека игр

Все игры оригинальные: они используют распространённые механики современных видеослотов, но не копируют названия, графику, аудио или ассеты сторонних провайдеров.

### 1. Сладкий каскад

Поле 7×7, кластерные выигрыши, каскады, клеточные множители до ×100, «Сладкий взрыв», «Сладкий шторм», фриспины и медленная поколоночная прокрутка.

### 2. Фруктовая фиеста

5×4, 20 линий, wild/scatter. Во фриспинах выпавшие вайлды становятся липкими и сохраняются до завершения бонусной серии.

### 3. Храм тысячи путей

6×5, выигрыши по соседним барабанам слева направо, каскады и растущий множитель. Во фриспинах множитель переносится между вращениями и может расти до ×10.

### 4. Джунгли: Золотой тотем

5×3, классические линии и золотые монеты. 6+ монет запускают hold-and-respin: монеты фиксируются, новые монеты сбрасывают счётчик респинов обратно до трёх, а заполнение всего поля даёт дополнительный бонус.

### 5. Кристальный реактор

8×8, кластерные выигрыши и каскады. Бомбы рядом с выигрышным кластером взрывают область 3×3, добавляя цепные удаления и дополнительную выплату. Во фриспинах бомбы встречаются чаще.

### 6. Свиток солнца

5×3, 10 линий. 3+ свитка запускают фриспины и выбирают один обычный символ. Во время бонуса выбранный символ расширяется на весь барабан перед подсчётом линий.

### 7. Неоновый разгон

5×5, выигрыши по путям, tumble-механика и растущее «напряжение». Во фриспинах множитель напряжения не сбрасывается между вращениями и может достигать ×10.

## Общая архитектура игр

- единый аккаунт и единый виртуальный рублёвый баланс;
- расчёт результата выполняется на PHP-сервере;
- браузер получает уже рассчитанный сценарий и только проигрывает анимацию;
- каждая ставка и выигрыш записываются в `wallet_transactions`;
- каждый раунд записывается в `game_rounds`;
- индивидуальный прогресс игры хранится в `user_game_states`;
- новые игры регистрируются через `app/game_catalog.php`;
- серверные движки новых игр находятся в `app/extra_games.php`;
- общий API новых игр: `api/game/arcade-spin.php`;
- общий адаптивный интерфейс: `play.php`, `arcade-game.js`, `arcade.css` и `arcade-themes.css`.

## Безопасность баланса

Изменение баланса выполняется внутри транзакции MySQL с `SELECT ... FOR UPDATE`. Ставка списывается и выигрыш начисляется сервером. Изменение JavaScript или значений в DevTools не меняет серверный баланс аккаунта.

## Важно

Текущая версия использует только **виртуальный игровой баланс**. Реальные пополнения, вывод средств и платёжные системы не подключены. Для эксплуатации с реальными деньгами потребуются отдельная юридическая/регуляторная инфраструктура, KYC/AML, responsible gaming, сертифицированный RNG, аудит и платёжный контур.
