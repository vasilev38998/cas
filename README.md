# CandyClub — аккаунтная игровая платформа

PHP/MySQL-сайт с регистрацией, авторизацией, серверным виртуальным балансом, журналом операций и серверным расчётом игровых раундов.

## Стек

- PHP 8.2+
- MySQL / MariaDB
- PDO
- HTML/CSS/JavaScript без Node.js и без сборки на хостинге
- PHP sessions + HttpOnly/SameSite cookies
- `password_hash()` / `password_verify()`
- CSRF-защита форм и игрового API
- GitHub Actions: PHP lint, JavaScript syntax check и smoke-тест игровых движков

Проект рассчитан на обычный shared-хостинг вроде Beget.

## Игровая философия

Текущий математический профиль новых игр — **высокая / очень высокая волатильность**. Это реализовано прозрачно через более редкие wild/scatter, более строгие пороги cluster/ways и более редкие бонусные механики. Персонального изменения шансов для конкретного пользователя нет: один и тот же серверный профиль используется для всех аккаунтов.

В игровых полях больше не используются системные emoji как основные символы. `arcade-symbols.js` содержит оригинальные встроенные SVG-наборы для каждой темы, поэтому символы одинаково выглядят и плавно масштабируются на телефоне и компьютере. У каждой игры также есть свой профиль остановки барабанов, anticipation, звук и win-анимации.

## Библиотека игр

Все игры оригинальные: они используют распространённые механики современных видеослотов, но не копируют названия, персонажей, графику, аудио или ассеты сторонних провайдеров.

### 1. Сладкий каскад

7×7, выигрышные кластеры теперь начинаются с 6 символов. Scatter и множители стали реже, «Сладкий взрыв» появляется позже в длинной каскадной серии, а шторм заряжается медленнее. Сохранились множители клеток до ×100, фриспины и поколоночная прокрутка.

### 2. Фруктовая фиеста

5×4, 20 линий и редкие wild/scatter. Во фриспинах выпавшие вайлды становятся липкими и сохраняются до завершения серии. Отдельный SVG-набор фруктов, колокола, семёрки, бриллианта, wild и бонуса.

### 3. Храм тысячи путей

6×5, выигрыши по соседним барабанам слева направо, каскады и растущая сила храма. Ways-попадания и wild стали реже, зато длинная серия каскадов заметнее усиливает результат. Во фриспинах сила переносится между вращениями.

### 4. Джунгли: Золотой тотем

5×3, 10 линий и редкий hold-and-respin. 6+ монет фиксируются, новые монеты возвращают счётчик респинов к трём. Монеты выпадают реже, а полное заполнение поля даёт увеличенный дополнительный бонус.

### 5. Кристальный реактор

8×8. Выигрышный кластер теперь начинается с 6 одинаковых кристаллов. Бомбы встречаются реже, но при соприкосновении с победой взрывают область 3×3 и могут продолжить каскад. Во фриспинах вероятность бомб повышается.

### 6. Свиток солнца

5×3, 10 линий и очень высокая волатильность. 3+ свитка запускают фриспины и выбирают специальный обычный символ. Во время бонуса этот символ расширяется на весь барабан перед подсчётом линий.

### 7. Неоновый разгон

5×5, редкие ways, tumble и растущее напряжение. Во фриспинах напряжение не сбрасывается между вращениями и может достигать ×10. Отдельные неоновые SVG и более быстрая «электрическая» физика барабанов.

### 8. Небесный пантеон

6×5, оригинальная механика в духе «небесные силы + tumble + множители», но без копирования конкретной сторонней игры. 8+ одинаковых символов платят в любом месте сетки и исчезают. Редкие небесные сферы дают множители ×2–×100 только при выигрышном tumble. 4+ Врат запускают фриспины, где собранные сферы накапливают Небесный заряд между вращениями. Символы — лавровый медальон, небесная чаша, арфа, кольцо, крыло, молния и Врата.

## Общая архитектура игр

- единый аккаунт и единый виртуальный рублёвый баланс;
- расчёт результата выполняется на PHP-сервере;
- браузер получает уже рассчитанный сценарий и только проигрывает анимацию;
- каждая ставка и выигрыш записываются в `wallet_transactions`;
- каждый раунд записывается в `game_rounds`;
- индивидуальный прогресс игры хранится в `user_game_states`;
- каталог игр: `app/game_catalog.php`;
- базовые helper-функции: `app/extra_games.php`;
- высоковолатильные профили: `app/high_volatility_engines.php`;
- «Небесный пантеон»: `app/sky_pantheon.php`;
- серверный роутер: `app/arcade_v2.php`;
- общий API: `api/game/arcade-spin.php`;
- SVG-наборы: `arcade-symbols.js`;
- индивидуальные эффекты: `arcade-fx.css`;
- общий адаптивный интерфейс: `play.php`, `arcade-game.js`, `arcade.css`, `arcade-themes.css`.

## Безопасность баланса

Изменение баланса выполняется внутри транзакции MySQL с `SELECT ... FOR UPDATE`. Ставка списывается и выигрыш начисляется сервером. Изменение JavaScript или значений в DevTools не меняет серверный баланс аккаунта.

## Важно

Текущая версия использует только **виртуальный игровой баланс**. Реальные пополнения, вывод средств и платёжные системы не подключены. Для эксплуатации с реальными деньгами потребуются отдельная юридическая/регуляторная инфраструктура, KYC/AML, responsible gaming, сертифицированный RNG, аудит и платёжный контур.
